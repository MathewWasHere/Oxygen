# فست فود اکسیژن — OXYGEN

وب‌اپ فارسی، راست‌چین و موبایل‌محور سفارش مستقیم برای **فست فود اکسیژن** در فسا.
پروژه با Next.js 16، React 19، TypeScript و Tailwind CSS 4 ساخته شده و به‌صورت PWA نصب می‌شود.

## اطلاعات مجموعه

- آدرس: فسا، ابتدای فاز ۴، نرسیده به مجتمع گلشهر
- تلفن: `071-53340472`
- اینستاگرام: <https://www.instagram.com/fastfoodoxygen/>
- نقشه: <https://maps.app.goo.gl/qtRmApR5TeDQTy6z8>

## اجرای محلی

```bash
npm install
npm run dev
```

بیلد و بررسی کیفیت:

```bash
npm run lint
npm run build
```

خروجی استاتیک برای cPanel:

```bash
npm run build:cpanel
```

- پیتزا: ۱۷ آیتم
- برگر: ۴ آیتم
- ساندویچ: ۱ آیتم
- اسنک: ۳ آیتم
- سوخاری: ۵ آیتم
- پیش‌غذا: ۳ آیتم
- پاستا: ۱ آیتم
- سالاد: ۱ آیتم
- نوشیدنی: ۶ آیتم

هر عکس در `public/food/` با دو خروجی WebP قرار دارد:

- `<slug>.webp` با ابعاد ۸۰۰×۸۰۰
- `<slug>-sm.webp` با ابعاد ۴۰۰×۴۰۰

قیمت‌ها هنوز اعلام نشده‌اند؛ مقدار موقت همه آیتم‌ها در `src/lib/data/catalog.ts` صفر است و رابط کاربری عبارت «قیمت به‌زودی» را نشان می‌دهد. افزودن آیتم بدون قیمت به سبد خرید غیرفعال است.

## برند و رسانه

- لوگوهای `public/brand/` مستقیماً از `OxygenLogoPack.html` استخراج و برای حالت روشن/تیره آماده شده‌اند.
- پالت رسمی: Crimson `#E0163D`، Red `#DA291C`، Gold `#FFC72C`.
- favicon، آیکون‌های PWA، maskable و Apple Touch از آیکون رسمی اکسیژن تولید شده‌اند.
- عکس هدر از کلاژ عکس‌های واقعی منوی ارسالی ساخته شده است.
- فونت‌های SnappWeb 2.0 از فایل‌های ارسالی WOFF (با پسوند اولیه `.txt`) به نام صحیح `.woff` منتقل شده‌اند.

## مسیرهای اصلی

- `/` صفحه اصلی
- `/menu` منوی کامل
- `/product/[slug]` جزئیات محصول
- `/cart` سبد خرید
- `/checkout` تسویه حساب آزمایشی
- `/orders` سفارش‌ها
- `/account` حساب کاربری
- `/admin` پنل مدیریت آزمایشی

## نکات نسخه آزمایشی

- کد OTP آزمایشی: `۱۲۳۴۵`
- کد تخفیف آزمایشی: `OXYGEN10` یا `FASA20`
- ساعت کاری و شعار فعلاً از نسخه مبدأ حفظ شده‌اند و باید با مجموعه تأیید شوند.
- لینک تلگرام هنوز placeholder است و باید تعیین تکلیف شود.
- دامنه `oxygen.ir` در metadata موقت است و قبل از انتشار باید با دامنه نهایی جایگزین شود.
